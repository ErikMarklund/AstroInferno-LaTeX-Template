# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](http://keepachangelog.com/en/1.0.0/)
and this project adheres to [Semantic Versioning](http://semver.org/spec/v2.0.0.html).

This template is derived from the DnD5e LaTeX Template (https://github.com/rpgtex/DND-5e-LaTeX-Template), and thefork was made at commit f2b562a60bb03c688ea0d145144404deb924a2f7. One bug-fix from a pull request was cherry-picked to overcome issues with new LaTeX distribution (commit 0350b6ced20e4e77a9ac6389e08f34a0797caeb9).

This changelog is now flushed to only incorporate changes for the Astro Inferno template. For earler DnD5e changes, see its own changelog. Changelog flushed at commit 7afbaf868d2cb30d807efbb95703cba258a82077.
